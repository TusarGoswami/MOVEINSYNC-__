P0 Blocker • Critical Defect

Issue #1: "App Not Installed from Play Store" Crash Loop

💬 Verbatim User Testimony
"after 2-3 days it says cannot open as not installed from play store. I need to install again"
— Pratik Gadge (3★)
"always crashes, giving an error that this app is not downloaded from app store... facing this issue since 3 months"
— Vishal Gomes & Bhavani M. (1★)
"developer forgot make it compatible to android 17... useless app need to uninstall very frequently"
— Byategowda VG (1★)
🔍 Root Cause & Engineering Fix

Root Cause: Google Play Integrity API attestation handshake failing or timing out during startup. When background dynamic feature updates execute on Android 14–17 / Pixel builds, installer package checks return null, triggering a client-side hard kill.

  • Relax Client Kill-Switch: Remove blocking hard aborts during launch; replace with asynchronous re-attestation or telemetry logging.
  • 7-Day Lease Model: Implement a cryptographic local attestation lease to prevent daily validation crashes.
  • Split-APK Key Alignment: Audit Play App Signing keys across base and dynamic feature modules.
Target KPI: Zero Play Store installation crash events; 70% reduction in daily 1★ reviews.

Issue #2: Forced Rating Gate & In-App Manipulation

💬 Verbatim User Testimony
"forcing me to give rating after every ride, so I came here to give you 1 star. because if I don't rate, I can't use the app as there is no skip option."
— Amit Singh Bhandari (1★)
"The Move In Sync app needs to seriously rethink its rating system. It's frustrating that users are only given options like 4 or 5 stars, with no way to rate 1, 2, or even 3. This completely undermines transparency."
— Anonymous Commuter (2★)
"there is no meaning of rating feature. driver themself gives rating and then it get locks."
— Neeraj Srivastav (3★)
🔍 Root Cause & Engineering Fix

Root Cause: Aggressive in-app review gate with missing dismissal button, combined with internal rating filters suppressing low ratings. Commuters feel silenced and retaliate on Google Play Store.

  • Visible "Skip" Button: Add clear, instantaneous dismissal to all post-ride prompts. Never lock core commute tabs.
  • Exponential Backoff Policy: If dismissed, suppress rating prompts for 30 days or 10 completed rides.
  • Transparent Internal Feedback: Allow honest 1–5 star ratings internally with mandatory root-cause tags (AC, Driver Speeding, Detour).
Target KPI: Immediate cessation of retaliatory 1★ reviews; authentic internal CSAT capture.

Issue #3: Session Disconnects at Corporate Gates

💬 Verbatim User Testimony
"Most frustrating aspect of this app is, when cab is waiting for you and you are in hurry, you will be logged out with no access to cab number/otp/call option... I use multiple workplace apps like smartq, pluxee etc but none have this issue"
— Anonymous (2★, 5 Upvotes)
"keep logout need otp login every time, not stable connectivity. timesout"
— Venkataramanaswamy (2★)
"App logout if internet connection is not available for a moment"
— Anonymous Commuter (2★)
🔍 Root Cause & Engineering Fix

Root Cause: Commuters exiting corporate campuses experience sudden 5GHz Wi-Fi to cellular carrier handover. Brief 2-second socket disconnects trigger OkHttp interceptor failures, incorrectly purging local authentication tokens.

  • Resilient Auth Interceptor: Decouple network timeouts from token revocation. Never clear session on transport drops.
  • Offline-First Ride Pass: Cache active trip metadata (Vehicle Number, Driver Contact, 4-digit Boarding OTP) in local EncryptedSharedPreferences.
  • Zero-Bar Accessibility: Commuters can view their OTP and boarding pass even in basement parking lots with zero connectivity.
Target KPI: Zero session drops during pickup window; elimination of gate dispute delays.

Issue #4: Algorithmic Routing Failures & "Bharat Darshan"

💬 Verbatim User Testimony
"my house is 40min from office it take 2.5 hours for me to reach home"
— Diwesh Sharma (1★)
"The routing algorithm is pure genius: it clubs passengers from two different states into one cab at 8 AM... If you want a free Bharat Darshan tour before reaching office, this is it"
— Ronin (1★)
"routematic has better service... they are not making shorter routes they schedule long and time taking routes"
— Umesh & Dev Chauhan (1-2★)
🔍 Root Cause & Engineering Fix

Root Cause: Vehicle Routing Problem (VRP) solver over-optimizes for vehicle seat occupancy rate (SOR) to reduce enterprise cab counts, without an individual passenger detour factor ceiling.

  • Hard Algorithmic Detour Cap: Enforce hard mathematical constraint: Max Commute = Min(1.4 × Direct Route Time, Direct Time + 35 mins).
  • Automated Route Splitting: Trigger cab split when passenger pairing crosses detour threshold.
  • Proactive Traffic Canaries: Alert enterprise facilities desks and commuters if corridor congestion pushes trip >15 mins over SLA.
Target KPI: Commuter detour ratio capped at <1.35x direct travel time; 75% drop in detour complaints.
